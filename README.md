# Fina

App de finanzas personales para México: anota un gasto en 3 segundos ("galleta 30") desde la app o por WhatsApp, y crece contigo desde lo básico hasta presupuestos, deudas, inversiones y finanzas en pareja.

La especificación completa está en [`docs/INSTRUCCIONES-APP-FINANZAS.md`](docs/INSTRUCCIONES-APP-FINANZAS.md).
